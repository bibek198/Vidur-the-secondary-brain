A company brain that knows who owns what, why it was decided, and what just changed.

Decision Brain models the Kubernetes project as a company: SIGs are teams, KEPs are decisions, issues and pull requests are the conversations, and OWNERS files are code ownership. Everything lives in one FalkorDB graph that updates itself as the project changes, and every answer shows its sources, its graph path and the Cypher behind it.

  • Answers you can checkClaude picks graph tools; it never writes Cypher. Each fact cites a GitHub source, and a guard rejects anything uncited.
  • Real timeGitHub webhooks, a poller and git diffs stream into the graph. A change is answerable in about 1 s, and earlier answers are flagged outdated.
  • Time travelEvery status, lead and approver has dates, so you can ask how things stood at any past release.
  • Measured honestly49/50 correct vs 15/50 for vector-only search on the same data; 84/90 vs 32/90 while two years of changes replayed.
Replay mode: recorded answers (no API key). The graph, Cypher and live feed are real.
